# 学了吗

一款由 AI 喵助手陪伴的学习打卡与时间管理小程序。

## 当前功能

- 可滑动的 29 天打卡日期条，支持完整月历切换和补卡
- 任务新建、编辑、删除、打卡和本地持久化
- 番茄钟、深度专注、正念计时和浏览器内白噪音
- 无需 API Key 的本地学习规划助手
- 基于 Web Speech API 的普通话语音输入（建议使用 Chrome / Edge 的 HTTPS 环境）
- 分板块原创学喵动作：打卡庆祝、AI 思考、伏案专注和奖牌成就
- 智能日程：按日期快速录入、四象限编辑、日历任务标记和基于时间/优先级的下一步建议
- 场景化专注：粉色番茄冲刺、深蓝潜行专注和薄荷绿正念呼吸，每种模式有独立的氛围与白噪音

用户数据仅保存在当前浏览器的 `localStorage`，本项目不上传打卡记录。
